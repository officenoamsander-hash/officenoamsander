# חיבור מערכת הגבייה ל-Google Sheets

הגיליון: https://docs.google.com/spreadsheets/d/1Yvw4z8rsw5L8egJC_WaJuNNmm6ZE67rDvxeXCntvpz8

1. בגיליון: **תוספים ← Apps Script** (או script.google.com ← פרויקט חדש).
2. הדבק את `Code.gs` בקובץ Code.gs, וצור קובץ HTML בשם `Index` והדבק בו את `Index.html`.
3. **Deploy ← New deployment ← Web app**:
   - Execute as: **User accessing the web app**
   - Who has access: **Anyone with Google account**
4. שתף את הגיליון (עריכה) עם מרגלית. רק מי שיש לו גישה לגיליון יוכל לקרוא ולכתוב דרך האפליקציה.
5. שלח למרגלית את כתובת ה-Web app. בכניסה הראשונה היא תאשר הרשאות.

הערות: עמודה Q בגיליון שומרת את יומן הפניות והתשלומים של האפליקציה — לא למחוק. אפשר לערוך את שאר העמודות ישירות בגיליון, והשינויים ייקלטו בטעינה הבאה של האפליקציה.
